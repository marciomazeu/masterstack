==================================================
NOTAS DE DEPLOY - DIGITALOCEAN (UBUNTU)
==================================================

1. DIRETÓRIO DO APP NO SERVIDOR:
/var/www/masterstack

2. ARQUIVO DE SERVIÇO SYSTEMD (.NET)
Criar em: /etc/systemd/system/masterstack.service
--------------------------------------------------
[Unit]
Description=MasterStack .NET Web App

[Service]
WorkingDirectory=/var/www/masterstack
ExecStart=/usr/bin/dotnet /var/www/masterstack/MasterStack.dll
Restart=always
RestartSec=10
KillSignal=SIGINT
SyslogIdentifier=masterstack
User=www-data
Environment=ASPNETCORE_ENVIRONMENT=Production
Environment=ConnectionStrings__DefaultConnection="Host=localhost;Database=masterstack;Username=postgres;Password=MUDE_AQUI"

[Install]
WantedBy=multi-user.target
--------------------------------------------------

3. CONFIGURAÇÃO BÁSICA DO NGINX (PROXY REVERSO)
Criar em: /etc/nginx/sites-available/default
--------------------------------------------------
server {
    listen        80;
    server_name   seudominio.com www.seudominio.com;
    location / {
        proxy_pass         http://127.0.0.1:5000;
        proxy_http_version 1.1;
        proxy_set_header   Upgrade $http_upgrade;
        proxy_set_header   Connection keep-alive;
        proxy_set_header   Host $host;
        proxy_cache_bypass $http_upgrade;
        proxy_set_header   X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header   X-Forwarded-Proto $scheme;
    }
}
--------------------------------------------------

4. COMANDO PARA GERAR SSL (HTTPS) APÓS CONFIGURAR NGINX:
sudo certbot --nginx -d seudominio.com -d www.seudominio.com
